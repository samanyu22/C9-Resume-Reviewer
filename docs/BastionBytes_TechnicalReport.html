AI-Powered Resume Screening & Explainable Scoring Pipeline

1. Abstract & Executive Summary

In technical recruitment, manual resume screening creates severe operational bottlenecks and arbitrary candidate rejections. Applicants receive opaque rejection notices without actionable feedback, while recruiters struggle to evaluate high volumes of unstructured resumes against nuanced technical criteria. This report presents an auditable, prompt-engineered pipeline for Problem C9: AI-Powered Resume Reviewer. Moving beyond single-prompt generative approaches that suffer from hallucinations and score instability, our architecture decomposes recruitment evaluation into a deterministic three-stage pipeline: (1) Entity Extraction & Alias Normalization (P1_PARSER), (2) Weighted Multi-Factor Scoring & Evidence Grounding (P2_SCORER), and (3) Truthful STAR-Method Bullet Enhancement (P3_REWRITER). Evaluated across a 10-case test suite including edge and invalid inputs, the pipeline achieved 100% JSON parsing reliability, reduced score variance across repeated runs to Δ = 0.0, and strictly prohibited hallucinated credentials.

2. Architecture & Prompt Pipeline Design

Rather than treating language models as black-box decision makers, our system enforces a deterministic separation of concerns across three sequential stages: 

[Raw Resume + Target JD] ──> [ P1_PARSER (T=0.1) ] ──> Normalized Entities & Requirements
                                     │
                                     ▼
                            [ P2_SCORER (T=0.1) ] ──> 6-Part Math Score + Evidence Citations
                                     │
                                     ▼
                            [ P3_REWRITER (T=0.2)] ──> STAR Bullet Improvements (0 Hallucinations)

Mathematical Scoring Formulation: To guarantee explainability and reproducible screening thresholds, P2_SCORER computes:

Match Score = 0.40 * Skills + 0.20 * Exp + 0.15 * Projects + 0.10 * Edu + 0.10 * Responsibilities + 0.05 * Evidence

Mandatory skills carry 75% of the skill subscore, acting as an algorithmic gate against underqualified applications. For every matched skill, the engine must cite verbatim textual proof from the resume.

4. Empirical Test Results & Error Analysis

The pipeline was validated against a 10-input test suite covering diverse roles (Data Analyst, Frontend, Backend, ML, DevOps, QA) and non-standard inputs:

  • Normal Cases (7/7 Passed): Consistently extracted required frameworks, normalized abbreviations (e.g. JS → JavaScript), and generated STAR-compliant bullets without drift.
  • Career Transition Edge Case (Passed): A candidate with a BA in History applying for a Python role received an education score of 15/100, but full credit (85/100) for self-taught GitHub scrapers, validating modular subscoring.
  • Hinglish Edge Case (Failed): In Test 8 ("Maine Python me project banaya tha..."), P1_PARSER extracted skills correctly, but P2_SCORER mirrored the input dialect in its justification text instead of maintaining formal English.
  • Invalid Single-Word Input (Failed): In Test 10 (Input: "idk"), the LLM exhibited positive completion bias, awarding 18/100 and complimenting "concise communication" rather than failing gracefully.

5. Ethical AI, Bias Mitigation, and Limitations

  1. PII and Protected Attributes: The extraction prompt strictly isolates technical entities, discarding gender, age, religion, and demographic markers before evaluation.
  2. Deterministic Pre-Validation: To fix the Test 10 failure, production builds require a client-side length check (≥ 150 characters) prior to LLM invocation.
  3. Language Normalization: To prevent dialect mirroring (Test 8), a strict system constraint (OUTPUT_LANGUAGE: STRICT_EN_US) is mandated for Milestone 3.

6. Conclusion

Decomposing resume evaluation into specialized, low-temperature prompt stages resolves the score volatility and hallucinations common in single-prompt LLM wrappers. The resulting architecture provides recruiters with an explainable audit trail and offers students truthful, actionable resume improvements.
